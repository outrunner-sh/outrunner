## Wave 1 — agent workflows and orchestration

Delivered October 28–29 by seven workstreams.

- **GitHub agent loop.** Mention `@outrunner` on an issue or PR to reach its session. CI failures and review feedback on a session’s PR are routed back to the agent. [#246](https://github.com/neevai-labs/outrunner/pull/246), [#249](https://github.com/neevai-labs/outrunner/pull/249)
- **Automation triggers.** Run automations weekly, monthly, once, or with a cron expression and timezone. Trigger runs through a secret webhook URL or additional GitHub events; configure run limits and retry behavior. [#248](https://github.com/neevai-labs/outrunner/pull/248), [#253](https://github.com/neevai-labs/outrunner/pull/253), [#263](https://github.com/neevai-labs/outrunner/pull/263)
- **Plan mode and composer tools.** Plan before building, approve a plan, compact the conversation with `/compact`, recall previous prompts, mention files, stop a turn with Esc, and see turn timings. Prompt recall has its own compatible database table. [#252](https://github.com/neevai-labs/outrunner/pull/252), [#264](https://github.com/neevai-labs/outrunner/pull/264), [#277](https://github.com/neevai-labs/outrunner/pull/277)
- **Diff comments.** Select diff lines and attach comments to the next message sent to the agent. [#265](https://github.com/neevai-labs/outrunner/pull/265)
- **Public API, MCP and CLI.** Create personal or organization API keys; manage sessions through REST `/api/v1`, signed session webhooks, and MCP `/api/mcp`. CLI commands cover listing, inspecting, creating, messaging, reading, waiting for, and deleting sessions. [#251](https://github.com/neevai-labs/outrunner/pull/251), [#259](https://github.com/neevai-labs/outrunner/pull/259), [#262](https://github.com/neevai-labs/outrunner/pull/262)
- **Session inbox and notifications.** Group sessions by their standing, search and manage them in a list, and receive notifications when a turn finishes, input is needed, an error occurs, or a PR opens or merges. [#255](https://github.com/neevai-labs/outrunner/pull/255), [#260](https://github.com/neevai-labs/outrunner/pull/260)
- **Missions and Runners.** Coordinate worker sessions through Mission tools and MCP. Deliver Runner turns, PR changes, and events once; show workers and news cards in the sidebar and Runners pane. Introduce Runner/Ship terminology and immediate cached painting for Missions and Triage. [#272](https://github.com/neevai-labs/outrunner/pull/272), [#273](https://github.com/neevai-labs/outrunner/pull/273), [#274](https://github.com/neevai-labs/outrunner/pull/274), [#278](https://github.com/neevai-labs/outrunner/pull/278), [#284](https://github.com/neevai-labs/outrunner/pull/284)
- **Session and PR correctness.** Make Stop end the turn, display prompts taken mid-turn, keep large files out of memory, recover stuck state after restarts or idle boxes, avoid resending returned prompts, require a clean PR before merging, and deduplicate Slack PR events. [#254](https://github.com/neevai-labs/outrunner/pull/254), [#257](https://github.com/neevai-labs/outrunner/pull/257), [#261](https://github.com/neevai-labs/outrunner/pull/261), [#266](https://github.com/neevai-labs/outrunner/pull/266)
- **Early audit log.** Add an organization audit log. This was originally planned for wave 2 and landed early. [#245](https://github.com/neevai-labs/outrunner/pull/245)
- **CI security cleanup.** Remove and disable a workflow that exposed secret values in build logs. Secret rotation and historical log removal were requested separately; completion is not verified by this changelog. [#250](https://github.com/neevai-labs/outrunner/pull/250)

## Wave 2 — richer sessions, agent tools and review

Delivered October 29 by eight workstreams; all 26 original PRs are merged.
